Máy FlexMix

Chủ động hỏi lệnh (long-poll), xử lý menu/kho và trả kết quả.

Ở server: SQLite lưu tài khoản, phiên, máy, quyền và mã mời; RAM giữ trạng thái online và hộp thư lệnh.Ở máy: lưu menu và kho; xử lý lệnh rồi trả kết quả cho server.

App dùng token của người dùng. Máy dùng product key. Server không lưu menu/kho của máy; máy chủ động kết nối tới server, không cần mở API trên máy.

Mục 2

Bắt đầu sử dụng

Server, app và máy phải cùng truy cập được địa chỉ server. Máy cần cấu hình riêng trước khi ghép đôi hoặc chạy relay.

1. Khởi động server

Từ thư mục gốc dự án, chạy:

python -m server.main
# hoặc chọn cổng khác
python -m server.main --port 8001

Mặc định server nghe trên 0.0.0.0:8000. Nếu muốn gửi OTP qua email, cấu hình SERVICE_EMAIL và SMTP_PASSWORD trong server/config/.env.

server/START.md · server/service/README.md

2. Cấu hình và chạy máy

Tạo machine/config/machine.env riêng cho từng máy; file chứa MACHINE_NAME, PRODUCT_KEY và SERVER_URL.

python -m machine.config.create_env --name FlexMix-02 --server http://<IP server>:8000
python machine_qr.py --from-env
cd machine
python main.py

Pairing Bluetooth chạy riêng bằng python3 -m machine.pairing.machine_bluetooth_pair trên Raspberry Pi.

machine/README.md · machine/pairing/README.md

3. Cài và kết nối app

Build từ app/flutter_app với địa chỉ server mà điện thoại truy cập được. Sau khi mở app: đăng ký tài khoản và xác minh OTP, đăng nhập, vào tab Máy để quét QR hoặc ghép Bluetooth. Nếu không có Raspberry Pi, các công cụ mô phỏng nằm trong tests/README.md.

flutter build apk --release --dart-define=SERVER_URL=http://<IP server>:8000
app/flutter_app/README.md

4. Nạp app lên điện thoại qua USB

Dùng cho điện thoại Android. Máy tính cần adb (có sẵn trong Android SDK platform-tools).

  1. Trên điện thoại, vào Cài đặt → Thông tin điện thoại, chạm 7 lần vào Số hiệu bản tạo để bật Tùy chọn nhà phát triển.
  2. Vào Tùy chọn nhà phát triển rồi bật Gỡ lỗi USB.
  3. Cắm cáp USB (loại truyền dữ liệu, không phải cáp chỉ sạc). Khi điện thoại hỏi có cho phép gỡ lỗi USB không, chọn Cho phép.
  4. Kiểm tra kết nối: máy phải hiện với trạng thái device. Nếu hiện unauthorized, mở khóa điện thoại và chấp nhận lại hộp thoại.
  5. Cài APK đã build, hoặc để Flutter tự build và cài.
adb devices

# cài file APK đã build (chạy trong app/flutter_app)
adb install -r build/app/outputs/flutter-apk/app-release.apk

# hoặc: build rồi cài bản release lên máy đang cắm
flutter install

# hoặc: chạy bản debug, có hot reload và log
flutter run --dart-define=SERVER_URL=http://<IP server>:8000

Không có cáp thì có thể gửi file APK sang điện thoại (Zalo, Drive, email…), mở file và cho phép cài ứng dụng không rõ nguồn gốc.

Lỗi thường gặpINSTALL_FAILED_UPDATE_INCOMPATIBLE: điện thoại đang có bản app ký bằng khóa khác (ví dụ bản debug và bản release). Gỡ app cũ bằng adb uninstall com.example.simple_app hoặc gỡ trên điện thoại, rồi cài lại. Nếu adb devices không thấy máy, thử đổi cáp hoặc cổng USB, rồi chạy adb kill-server và adb devices.
app/flutter_app/README.md
Bí mật máyProduct key là thông tin đăng ký và xác thực của máy. Giữ file machine.env ngoài git; không chia sẻ key hoặc ảnh QR đăng ký công khai.

Mục 4

Từng thành phần và nơi lưu dữ liệu

App Android

lib/app lắp ghép màn hình; lib/config giữ URL/route; lib/core giữ HTTP, phiên, gói QR/Bluetooth; mỗi lib/feature giữ request, state và UI của mình.

Dashboard có năm tab: Tổng quan, Đơn hàng, Sản phẩm, Kho, Máy. Chuyển máy sẽ bỏ dữ liệu menu/kho cũ.

Cấu trúc app

Server Python

server/main.py nạp trực tiếp tám module và mở HTTP. Route tập trung tại server/config/routing.py. Tài khoản, phiên, máy, quyền và mã mời nằm trong SQLite; các luồng Menu/Kho chỉ kiểm quyền và chuyển lệnh.

Cách chạy server · Quy ước module

Relay và hộp thư

machine/main.py chỉ chạy một vòng hỏi lệnh → xử lý → trả kết quả (không còn thread heartbeat). Hộp thư lệnh, trạng thái online và kết quả chờ ở RAM server, trong server/lib/machine/machine_transport.py. Máy không cần biết ID được server cấp.

Luồng relay

Dữ liệu trên máy

Menu dùng dữ liệu tại machine/database/database.db. Kho dùng tầng MySQL của phần mềm máy pha version1.0, không nằm trong repo này. Pairing Bluetooth là tiến trình riêng, không tự khởi chạy cùng relay.

Mục 6

Vận hành và kiểm tra

Cấu hình cần có

  • Server: cổng HTTP mặc định 8000; SMTP trong server/config/.env nếu dùng OTP email.
  • Máy: MACHINE_NAME, PRODUCT_KEY, SERVER_URL trong machine/config/machine.env.
  • App: truyền SERVER_URL khi build hoặc sửa app_config.dart.

Kiểm tra cơ bản

.\tests\test.ps1 -Flow py
cd app/flutter_app
flutter analyze
flutter test ../../tests/flutter

Kiểm tra end-to-end trên điện thoại: python tests/e2e/run_e2e.py. Bộ này cần ADB và môi trường theo hướng dẫn test.

Sau khi server khởi động lại, phiên token trong SQLite vẫn còn. OTP đang chờ, trạng thái online và lệnh trong RAM mất; máy tự poll lại là online trở lại. Máy online theo long-poll chỉ là dấu hiệu còn kết nối, chưa bảo đảm tác vụ tiếp theo thành công.
