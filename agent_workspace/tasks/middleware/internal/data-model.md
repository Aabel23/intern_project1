## Từ điển dữ liệu

| Dữ liệu | Nơi sống | Đọc/ghi, thời hạn | Quy tắc |
| --- | --- | --- | --- |
| Token thô | App; request server | Session 30 ngày, logout xóa hash | Không máy/log; token không thay role |
| token_hash / expires_at | SQLite app_sessions | SHA-256 lookup; epoch expiry | Không cache liên request trước invalidation |
| product_key_hash | SQLite machines | Key JSON hash→machine_id | Người giữ key thô vẫn có thể giả máy |
| manager role | SQLite machine_managers | Owner/manager theo action; unique owner | Đọc quyền cùng conn/transaction cần khóa |
| HOP_THU | RAM transport | Chưa take; timeout chưa lấy→xóa | Không sống qua restart; bound cần task riêng |
| DANG_CHO | RAM transport | id→machine_id/Queue; xóa finally | Result sai máy/trễ không chuyển request khác |
| Heartbeat | RAM transport | mark_seen epoch; online trong 15s | Offline không nói command chưa chạy |
| IP_REQUESTS | RAM limiter | Fixed 60s monotonic, 1000 IP hiện tại | Full-table policy cần test |
| Context | Request đề xuất | ID/route/timing/state/leases | Không global hoặc copy body vào log |
| Menu/Kho/version | Máy | Validate version, transaction máy | Client timeout không rollback máy |
