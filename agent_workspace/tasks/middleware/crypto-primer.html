HPKE Base single-shot (RFC 9180)

Gói KEM + KDF + AEAD vào một lần gọi thư viện cho mỗi attempt, cho ra enc và ct.

Request app → server; máy dùng cùng mô hình envelope cho heartbeat, poll, result.

Lưu ý
Base mode không chứng minh người gửi là ai, nên cần chữ ký ngoài (thẻ 12). Không tự viết, chỉ dùng thư viện có vector chuẩn. Suite chưa chốt.

KEM: X25519 là ứng viên

Trao đổi khóaĐề xuất R5
Làm gì
Từ khóa tạm của người gửi và khóa công khai server tạo bí mật chung; enc đi kèm gói (32 byte nếu X25519).

Nguồn ghi: "Thuật toán KEM cụ thể chưa chốt; X25519 là ứng viên nghiên cứu". Lộ khóa riêng server thì không còn forward secrecy.

Ví dụ: gói tin abcd

Khi dùng thật, khóa tạm ngẫu nhiên khiến mỗi lần ra byte khác.

"""Minh họa gói abcd bằng primitive tương đương (X25519 + HKDF-SHA256 + AES-256-GCM + Ed25519 + SHA-256).
Khóa giả công khai, KHÔNG phải suite đã chốt, KHÔNG phải test vector. In JSON để dựng trang."""
import hashlib, json, struct
from cryptography.hazmat.primitives.asymmetric.x25519 import X25519PrivateKey
from cryptography.hazmat.primitives.asymmetric.ed25519 import Ed25519PrivateKey
from cryptography.hazmat.primitives.kdf.hkdf import HKDF
from cryptography.hazmat.primitives import hashes, serialization
from cryptography.hazmat.primitives.ciphers.aead import AESGCM
from cryptography.exceptions import InvalidTag, InvalidSignature

RAW = dict(encoding=serialization.Encoding.Raw, format=serialization.PublicFormat.Raw)
def LP(x): return struct.pack(">I", len(x)) + x
def Tuple(*xs): return b"".join(LP(x) for x in xs)
def pub(k): return k.public_key().public_bytes(**RAW)

# Khóa giả cố định (công khai trong trang này)
srv = X25519PrivateKey.from_private_bytes(b"DEMO-server-kem-private-key-0001"[:32])
eph = X25519PrivateKey.from_private_bytes(b"DEMO-ephemeral-sender-key-00002"[:32].ljust(32, b"_"))
sig = Ed25519PrivateKey.from_private_bytes(b"DEMO-credential-signing-key-0003"[:32])

plaintext = b"abcd"
attempt_id = bytes(range(16))
# M rút gọn so với bảng §4 (chỉ minh họa): domain, version, route, attempt_id
M = Tuple(b"demo-packet-request", struct.pack(">H", 5), b"DEMO_ROUTE", attempt_id)

def derive(shared):
    okm = HKDF(algorithm=hashes.SHA256(), length=44, salt=None,
               info=Tuple(b"demo-hpke-like-info", M)).derive(shared)
    return okm[:32], okm[32:44]

def seal(pt):
    enc = pub(eph)
    shared = eph.exchange(srv.public_key())
    key, nonce = derive(shared)
    aad = Tuple(b"demo-aad-request", M)
    ct = AESGCM(key).encrypt(nonce, pt, aad)
    sigv = sig.sign(Tuple(b"demo-sig-request", M, enc, ct))
    env = struct.pack(">H", 5) + LP(M) + LP(enc) + LP(ct) + LP(sigv)
    return dict(enc=enc, shared=shared, key=key, nonce=nonce, aad=aad, ct=ct, sig=sigv, env=env)

def open_(env, claimed):
    ver = struct.unpack(">H", env[:2])[0]; p = 2; parts = []
    for _ in range(4):
        n = struct.unpack(">I", env[p:p+4])[0]; parts.append(env[p+4:p+4+n]); p += 4 + n
    if p != len(env): return "REJECT: dư byte cuối khung"
    M_, enc, ct, sg = parts
    try:
        sig.public_key().verify(sg, Tuple(b"demo-sig-request", M_, enc, ct))
    except InvalidSignature:
        return "REJECT: chữ ký sai (chặn TRƯỚC khi giải mã)"
    from cryptography.hazmat.primitives.asymmetric.x25519 import X25519PublicKey
    shared = srv.exchange(X25519PublicKey.from_public_bytes(enc))
    okm = HKDF(algorithm=hashes.SHA256(), length=44, salt=None, info=Tuple(b"demo-hpke-like-info", M_)).derive(shared)
    try:
        pt = AESGCM(okm[:32]).decrypt(okm[32:], ct, Tuple(b"demo-aad-request", M_))
    except InvalidTag:
        return "REJECT: tag AEAD sai"
    aid = M_[-16:]
    if aid in claimed: return "REJECT: replay, attempt_id đã claim"
    claimed.add(aid)
    return "OK: " + pt.decode()

r = seal(plaintext)
H = lambda b: b.hex()
out = dict(
    srv_pub=H(pub(srv)), eph_pub=H(pub(eph)), sig_pub=H(pub(sig)),
    plaintext_hex=H(plaintext), M=H(M), M_len=len(M), attempt_id=H(attempt_id),
    enc=H(r["enc"]), shared=H(r["shared"]), key=H(r["key"]), nonce=H(r["nonce"]),
    aad=H(r["aad"]), aad_len=len(r["aad"]),
    ct_all=H(r["ct"]), ct_body=H(r["ct"][:4]), tag=H(r["ct"][4:]), ct_len=len(r["ct"]),
    sig=H(r["sig"]), sig_len=len(r["sig"]),
    env=H(r["env"]), env_len=len(r["env"]),
)
# nhận
claimed = set()
out["rx_ok"] = open_(r["env"], claimed)
out["rx_replay"] = open_(r["env"], claimed)
# sửa 1 byte ciphertext
e = bytearray(r["env"]); idx = 2 + 4 + len(M) + 4 + 32 + 4  # byte đầu của ct
e[idx] ^= 0x01
out["tamper_ct_index"] = idx
out["rx_tamper_ct"] = open_(bytes(e), set())
# sửa 1 byte nhưng giả sử không có chữ ký (chỉ AEAD): kiểm tag
key, nonce = r["key"], r["nonce"]
bad = bytearray(r["ct"]); bad[0] ^= 1
try: AESGCM(key).decrypt(nonce, bytes(bad), r["aad"]); out["aead_only_tamper"] = "OK?!"
except InvalidTag: out["aead_only_tamper"] = "InvalidTag (tag AEAD không khớp)"
# AAD sai (đổi route trong header)
badaad = Tuple(b"demo-aad-request", M.replace(b"DEMO_ROUTE", b"DEMO_ROUTF"))
try: AESGCM(key).decrypt(nonce, r["ct"], badaad); out["aead_bad_aad"] = "OK?!"
except InvalidTag: out["aead_bad_aad"] = "InvalidTag (AAD khác: đổi 1 byte của route)"
# sai khóa người nhận
wrong = X25519PrivateKey.from_private_bytes(b"DEMO-wrong-server-key-000000009!"[:32])
sh2 = wrong.exchange(eph.public_key())
okm2 = HKDF(algorithm=hashes.SHA256(), length=44, salt=None, info=Tuple(b"demo-hpke-like-info", M)).derive(sh2)
try: AESGCM(okm2[:32]).decrypt(okm2[32:], r["ct"], r["aad"]); out["wrong_key"] = "OK?!"
except InvalidTag: out["wrong_key"] = "InvalidTag (sai khóa riêng người nhận)"
# chữ ký sai
try:
    sig.public_key().verify(r["sig"], Tuple(b"demo-sig-request", M, r["enc"], bytes([r["ct"][0] ^ 1]) + r["ct"][1:])); out["sig_tamper"]="OK?!"
except InvalidSignature: out["sig_tamper"] = "InvalidSignature"
# hash
out["sha256_abcd"] = hashlib.sha256(b"abcd").hexdigest()
out["sha256_abce"] = hashlib.sha256(b"abce").hexdigest()
bitdiff = bin(int(out["sha256_abcd"],16) ^ int(out["sha256_abce"],16)).count("1")
out["sha256_bitdiff"] = bitdiff
salt = bytes(range(16))
out["pbkdf2_salt"] = H(salt)
out["pbkdf2"] = hashlib.pbkdf2_hmac("sha256", b"abcd", salt, 200_000).hex()
import hmac as _h
out["hmac_abcd"] = _h.new(b"DEMO-hmac-key", b"abcd", hashlib.sha256).hexdigest()
# lặp lại 2 lần với cùng khóa: xác định (deterministic) — kiểm
out["deterministic"] = (seal(plaintext)["env"] == r["env"])
print(json.dumps(out, indent=1, ensure_ascii=False))
Mục 5

Kiến thức cần biết

Mã hóa, băm, MAC, chữ ký là bốn việc khác nhau

  • Mã hóa: giữ bí mật, có khóa, giải ngược được.
  • Băm: nhận dạng, không khóa, không giải ngược.
  • MAC (HMAC): chứng minh toàn vẹn bằng khóa chung.
  • Chữ ký: chứng minh ai gửi, khóa riêng ký, khóa công khai kiểm.
Nguồn: packet-security.html, keys.md

Khóa công khai và khóa riêng

  • Khóa công khai được phát cho mọi người; khóa riêng không rời thiết bị giữ nó.
  • HPKE Base: ai có khóa công khai server cũng tạo được gói, nên cần thêm chữ ký để biết người gửi.
thiết kế R5 §2

Nonce/IV không được lặp với cùng khóa

  • AEAD hỏng nghiêm trọng khi lặp nonce dưới một khóa (RFC 5116).
  • IV ngẫu nhiên 96-bit: q lần/khóa có xác suất trùng ≤ q(q−1)/2^97; q = 2^20 cho khoảng 6,94e-18 mỗi khóa.
  • Đó chỉ là cận va chạm, không phải toàn bộ độ an toàn AEAD.
thiết kế R5 §9 (toán có giả định)

AAD: bảo vệ phần không mã hóa

  • AAD (header, route, attempt_id) đi ở dạng rõ nhưng gắn vào tag; đổi 1 byte là mở thất bại.
  • Nhờ vậy không thể chuyển gói sang route hoặc ngữ cảnh khác.
thiết kế R5 §4

Mã hóa không làm gói "vô hình"

  • IP, thời điểm, kích thước và route HTTP ở nơi TLS kết thúc vẫn có thể bị thấy.
  • Plaintext ở UI, RAM, log, crash dump hoặc DB sau giải mã nằm ngoài lớp mã hóa đường truyền.
keys.md

Giới hạn đã nêu trong thiết kế

  • Server nghiệp vụ vẫn giải mã được: hai chặng độc lập, không phải E2EE app ↔ máy.
  • Không hứa ẩn danh, chống chối bỏ, chống lượng tử hay forward secrecy khi khóa recipient lâu dài bị lộ.
  • Mọi bảo đảm phụ thuộc thư viện đúng, CSPRNG tốt, trust anchor đúng và endpoint chưa bị chiếm.
