API và gói tin

POST gửi JSON; GET dùng query. Các ví dụ thể hiện cấu trúc trường dữ liệu. Token thuộc app; product_key thuộc máy nếu API yêu cầu.

Nhánh lỗi và lưu ý

Route đăng nhập giới hạn theo IP; logout không áp dụng giới hạn đó. Đăng nhập một bước: gửi lại khi mạng lỗi thì server kiểm lại và cấp token mới. Mật khẩu không gửi lại app; token lưu dạng hash trong database.
