Đăng ký máy

App lấy tên máy và product key bằng QR hoặc Bluetooth, rồi gửi một request đăng ký lên server. Người đăng ký đầu tiên trở thành chủ máy.

API và gói tinA. Lấy gói thông tin máyB. Đăng ký trên serverLưu ý

API và gói tin

POST gửi JSON; GET dùng query. Các ví dụ thể hiện cấu trúc trường dữ liệu. Token thuộc app; product_key thuộc máy nếu API yêu cầu.

Giao tiếp cục bộ giữa app và máy, chưa gọi server.

B. Đăng ký trên server

Nhánh lỗi và lưu ý

Product key không được trả trong danh sách máy; database lưu hash key. Đăng ký máy không cần máy online nếu app đã có gói pairing. Nhánh lỗi trả valid=false/message hoặc login_required khi phiên hết hạn.

Cấu trúc và transaction

machine_register_main.py → handle(request) nhận HTTP, chọn machine_register_process.py → receive_register(). Tác vụ kiểm dữ liệu trước phiên, chuẩn bị tên/hash và điều phối transaction.

Tên/key phải là chuỗi không trắng, tối đa 150/1024 ký tự. Tên được strip khi tạo; key được băm nguyên giá trị. Gửi lại cùng key giữ ID và tên hiện tại; type không bắt buộc.

SQL đọc nằm trong server/database/machine/machine_read.py; SQL tạo máy/gán chủ nằm trong machine_write.py. Các hàm database nhận cùng conn. BEGIN IMMEDIATE trước khi tìm máy; tạo máy và gán chủ cùng commit/rollback. Schema/index do init_db.py khởi tạo, giữ dữ liệu hiện có.

Response trả trên request POST ban đầu: thành công 200; lỗi dữ liệu/phiên/quyền 400; lỗi SQLite 503. Body tối đa 4096 byte. Không có request xác minh thứ hai hoặc lệnh gửi xuống máy.

Hiện chưa đối chiếu key với danh sách key nhà máy, chưa gán cửa hàng hoặc cấp credential.
