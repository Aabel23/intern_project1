Cổng máy: nhận lệnh và trả kết quả

Máy chủ động gọi server. Server dùng chung hộp thư lệnh để kết nối các feature app với máy; không mở endpoint riêng trên máy.

API và gói tin

POST gửi JSON; GET dùng query. Các ví dụ thể hiện cấu trúc trường dữ liệu. Token thuộc app; product_key thuộc máy nếu API yêu cầu.

Nhánh lỗi và lưu ý

Key sai trả HTTP 403. Hộp thư, LAN_THAY_CUOI và DANG_LAM nằm trong RAM; restart mất trạng thái chờ. Máy khác gửi ID không thuộc mình không được chuyển kết quả. Response da_nhan=true không bảo đảm có lệnh đang chờ tương ứng.

Cấu trúc và bên sử dụng

machine_link_main.py → handle(request) nhận HTTP và chọn tác vụ trong machine_link_process.py. Process xác minh key rồi gọi transport; SQL tra máy nằm trong server/database/machine/machine_read.py.

machine/main.py → run() chỉ có một vòng lặp (không còn thread heartbeat): hỏi lệnh → thực hiện → trả kết quả. poll_command() gọi /machine/command/poll; send_result() mở request mới tới /machine/result/send. Máy không gửi tín hiệu online riêng: server ghi "đã thấy" (mark_seen) mỗi lần poll và gửi kết quả; route /machine/heartbeat/send đã bỏ (404).

Menu/Kho gọi server/lib/machine/machine_transport.py → send() cho nhan_menu, cap_nhat_menu, nhan_kho và nap_kho. Link dùng take() lấy việc và deliver() ghép kết quả đúng máy/ID lệnh. Kết quả trả app trên request nghiệp vụ ban đầu. Machinelist chỉ đọc trạng thái online (is_online, last_seen_of).

Hộp thư, khóa, ID và trạng thái chờ giữ một nơi trong transport. Link không import sync hoặc diễn giải nghiệp vụ Menu/Kho. Refactor từng bên giữ hợp đồng thì không cần sửa bên còn lại; thay transport cần kiểm tra cả Menu/Kho.

Body tối đa 1 MB. Key phải là chuỗi không trắng, tối đa 1024 ký tự và được băm nguyên giá trị. JSON sai trả 400; key sai/chưa đăng ký trả 403; lỗi SQLite trả 503.

Kiểm tra: python -m unittest tests.python.test_machine_relay tests.python.test_server_modules -v. Relay dùng HTTP và vòng lặp máy thật với SQLite tạm/database máy giả, chưa kiểm chứng thiết bị vật lý.
