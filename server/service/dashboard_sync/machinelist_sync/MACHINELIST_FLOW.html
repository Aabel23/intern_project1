Tab Máy: danh sách, đổi tên và gỡ máy

Hai thao tác trong menu ⋮ của mỗi máy ở tab Máy. Cả hai đều là JSON gửi bằng POST tới server, có kèm token đăng nhập. Code server: machine_list_request.py (nhận POST) → machine_list_manage.py (kiểm tra và xử lý), SQL: machine_list_store.py.

API và gói tin

Mọi gói là JSON gửi bằng POST, Content-Type: application/json. Token hết hạn thì server trả login_required: true và app quay về màn hình đăng nhập.

Đổi tên máy

{"machine_id": "fm_...", "name": "<tên người dùng nhập>", "token": "..."}
→ 200 {"valid": true, "name": "...", "message": "Đã đổi tên máy"}
→ 400 {"valid": false, "message": "Chỉ chủ máy mới đổi tên được"}
→ 400 {"valid": false, "message": "Tên máy phải có 1-150 ký tự"}

Gỡ máy

{"machine_id": "fm_...", "token": "..."}
→ 200 {"valid": true, "deleted": true,  "message": "Đã gỡ máy khỏi quán"}   (chủ)
→ 200 {"valid": true, "deleted": false, "message": "Đã bỏ quản lý máy"}     (nhân viên)
→ 400 {"valid": false, "message": "Bạn không quản lý máy này"}

Đổi tên máy: từ lúc bấm nút

1Menu ⋮ → Đổi tên (machines_tab.dart, _rename())

Chỉ chủ máy thấy mục này. Hộp _RenameDialog điền sẵn tên hiện tại; bấm Lưu trả tên đã bỏ khoảng trắng hai đầu, tên rỗng hoặc bấm Hủy thì dừng.

2machine_list_request.dart, renameMachine()

POST /app/doi-ten-may với {machine_id, name, token}.

3machine_list_manage.py, rename_machine()

  1. machine_list_request.handle() đọc body (tối đa 4096 byte) rồi gọi flow.
  2. machine_list_manage.check_request(): token → user_id, kiểm tra machine_id; clean_name(): tên 1-150 ký tự.
  3. machine_list_manage.role_of(): phải là chủ máy.
  4. machine_write.rename_machine(): UPDATE machines SET name=?; trigger tự cập nhật updated_at.

4App cập nhật

Thành công thì controller.loadMyMachines() gọi /app/may-cua-toi, dòng máy hiện tên mới. Lỗi thì hiện SnackBar.

Gỡ máy: từ lúc bấm nút

1Menu ⋮ → Gỡ khỏi quán / Bỏ quản lý máy (_remove())

Chủ thấy "Gỡ khỏi quán", nhân viên thấy "Bỏ quản lý máy". Hộp xác nhận nói rõ hậu quả; bấm Gỡ máy / Bỏ quản lý mới đi tiếp.

2MachineApi.removeMachine()

POST /app/go-may với {machine_id, token}.

3machine_list_manage.py, remove_machine()

  1. machine_list_manage.check_request(): token → user_id, kiểm tra machine_id; BEGIN IMMEDIATE khóa ghi rồi role_of() đọc vai trò.
  2. Chủ: machine_write.delete_machine() xóa dòng machines; ON DELETE CASCADE xóa luôn quyền mọi nhân viên và mã mời. product_key_hash mất nên tem QR đăng ký lại được.
  3. Nhân viên: machine_write.remove_manager() xóa đúng dòng role='manager' của người đó.

4App cập nhật (dashboard_controller.dart, forgetMachine())

Bỏ máy khỏi danh sách; nếu đang chọn thì bỏ chọn, xóa menu/kho đang hiện. Sau đó loadMyMachines(); còn máy khác thì tự chọn máy đầu.

Máy bị gỡ hoặc bị thu hồi từ điện thoại khác (chủ gỡ máy, nhân viên đang mở app) cũng biến mất: loadMyMachines() lấy danh sách server làm chuẩn, chạy khi mở dashboard, khi đóng các màn thêm máy và khi kéo xuống để tải lại ở tab Máy.

Vài điểm cần biết

  • Sau khi chủ gỡ máy, máy pha vẫn gửi heartbeat bằng product key nhưng server trả 403 cho tới khi máy được đăng ký lại.
  • Nhân viên không thấy mục Đổi tên; server cũng từ chối nếu nhân viên gọi thẳng API.
