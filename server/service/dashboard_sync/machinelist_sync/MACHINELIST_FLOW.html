Danh sách, tên và quyền quản lý máy

App lấy danh sách máy thuộc tài khoản, đổi tên hoặc gỡ quyền. Cổng trạng thái đọc trạng thái online của máy (suy từ long-poll).

API và gói tin

POST gửi JSON; GET dùng query. Token thuộc app; product_key thuộc máy nếu API yêu cầu.

Nhánh lỗi và lưu ý

Nhân viên không đổi tên được dù tự gọi API. Gỡ máy bởi chủ làm mất quyền toàn bộ nhân viên; bỏ quyền bởi nhân viên không xóa máy. GET trạng thái hiện không yêu cầu token; không mô tả nó như API đã kiểm quyền.

Cấu trúc module

  • machine_list_main.py: cửa vào handle (POST), handle_get (GET), đọc JSON/query và trả response.
  • machine_list_get.py: list_my_machines kiểm phiên và SELECT; machine_status đọc trạng thái online trong RAM.
  • machine_list_rename.py: kiểm phiên, mã máy, tên và quyền chủ rồi UPDATE tên.
  • machine_list_remove.py: kiểm phiên, mã máy, BEGIN IMMEDIATE trước kiểm quyền; chủ DELETE máy, nhân viên gọi remove_manager.

SQL riêng nằm cùng luồng; phiên, HTTP, kiểm quyền và trạng thái online dùng helper chung. Gỡ máy cascade xóa quyền và mã mời, transaction rollback khi lỗi. Các luồng này không gửi lệnh xuống máy.

Header ghi trong gói tin là header do server đặt (http_json.send_json); khi lỗi 503 có thể kèm Retry-After. Ví dụ response ghi nhánh valid=true; lỗi thì body là {valid: false, message} (hết phiên kèm login_required). POST: body 1–4096 byte; valid=true trả 200, valid=false trả 400 (hết phiên kèm login_required=true). JSON sai trả 400; SQLite lỗi trả 503. Response luôn trả trên request ban đầu.
