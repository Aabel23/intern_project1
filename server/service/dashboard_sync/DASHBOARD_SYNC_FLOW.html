Đồng bộ dashboard

Mỗi tab dashboard của app là một module trong dashboard_sync/. Menu và Kho là dữ liệu của máy, đi qua cổng máy; tab Máy là dữ liệu của server. Chi tiết route và lỗi: README.md.

Đọc dữ liệu máy theo version

1App (products_sync.dart, ingredients_sync.dart)

Gửi version đang giữ (menu_version / version), lần đầu hoặc sau khi đổi máy là 0.

2Server: *_api.py → *_flow.py

sync_rules.check_access() (token → người dùng → quản lý máy → vai trò), *_verify.py kiểm version là số 0..2³²−1, rồi link_queue.send(). Kết quả máy đi nguyên về app, server không đọc và không lưu.

3Máy: machine/<tab>/..._flow.py

Đọc database, tính CRC32 của dữ liệu. Trùng version app gửi → {"status": "up_to_date", version}, không gửi lại dữ liệu. Khác → {"status": "ok", version, dữ liệu}; menu gói dữ liệu thành packet base64(zlib(JSON)).

4App

up_to_date: giữ danh sách đang hiện. ok: thay danh sách, lưu version mới.

Ghi dữ liệu máy

  • Menu (/app/gui-menu): app gửi kèm menu_version đang sửa. Máy đã có bản khác thì không ghi, trả conflict + menu mới nhất; khớp thì kiểm hết các dòng rồi ghi trong một transaction.
  • Kho (/app/nap-kho): target = id hoặc "all", value = "full" hoặc số gram. Máy nạp bằng hàm refill() của trang admin máy rồi dựng lại menu-data.js cho màn bán hàng.

Thêm một tab mới

  1. Server: folder dashboard_sync/<tab>_sync/ theo mẫu api / verify / flow (androidv0.1/MODULE_PATTERN.md), quyền trong sync_rules.py, route trong config/routing.py, thêm vào MODULES của server/main.py.
  2. Máy: folder machine/<tab>_sync/ với bảng COMMANDS, gộp vào COMMANDS của machine/main.py.
