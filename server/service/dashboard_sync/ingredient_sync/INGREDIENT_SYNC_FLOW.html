App xem kho hoặc yêu cầu nạp. Máy giữ dữ liệu kho; server chỉ xác thực và chuyển lệnh/kết quả.

API và gói tin

POST gửi JSON; GET dùng query. Các ví dụ thể hiện cấu trúc trường dữ liệu. Token thuộc app; product_key thuộc máy nếu API yêu cầu.

Nhánh lỗi và lưu ý

Gói sai trả 400; hết phiên 401; thiếu quyền 403; offline 503; máy lỗi/timeout 502. Luồng nạp hiện không có cơ chế conflict phiên bản như cập nhật menu.

Cấu trúc module

  • machine_ingredient_main.py: cửa vào handle, đọc JSON tối đa 4096 byte, chọn luồng và trả HTTP.
  • machine_ingredient_get.py: nhan_kho kiểm quyền rồi version nguyên 0..2^32-1 (mặc định 0), gửi lệnh nhan_kho.
  • machine_ingredient_refill.py: nap_kho kiểm quyền rồi target/value bằng is_refill, gửi lệnh nap_kho.

Validate nằm trong từng file luồng. Bool không được dùng làm số. Target là ID nguyên dương hoặc all; value là full hoặc số gram 0..99999999.99. Target=all chỉ nhận value=full. Owner và manager đều được xem/nạp kho.

check_access và send dùng lib chung, không tạo hộp thư riêng. Token không gửi xuống máy. Server trả nguyên kết quả/status của transport, gồm warning, trên request app ban đầu. JSON sai trả 400.
