## Time bootstrap trigger cụ thể

Chỉ bootstrap trước request khi chưa có offset hoặc monotonic age>=300s. Public INVALID_ENVELOPE không đủ để nhận biết skew: bỏ time cache rồi trả lỗi call hiện tại, không auto retry/bootstrap ngay và không replay write. Lần call mới do caller khởi tạo sẽ bootstrap trước gửi. Không có code CLOCK_SKEW hay heuristic phân loại từ error message. Test INVALID_ENVELOPE→không gửi lại write, call kế tiếp→bootstrap→request mới; cache age300s→bootstrap trước request. Transport retry account vẫn do user chủ động như các mục trước.
